# Rekap Pesanan Mama

## Publikasikan di GitHub Pages
1. Ekstrak ZIP ini.
2. Unggah index.html dan .nojekyll ke folder utama repository GitHub.
3. Buka Settings > Pages.
4. Pada Source, pilih Deploy from a branch.
5. Pilih branch main dan folder / (root), lalu Save.
6. Tunggu proses selesai dan buka tautan situs yang ditampilkan GitHub.

Data pesanan tersimpan pada browser dan perangkat masing-masing. Unduh CSV secara berkala sebagai cadangan. Data dari file HTML lokal tidak otomatis berpindah ke alamat GitHub Pages.
